### 🔧 Featured projects

**[AutoGluon-Agent](https://github.com/MaxPignatti/AutoGluon-Agent)**: a Claude Code plugin with a Python harness. You give it a CSV and a one-line goal, and it runs a leakage-checked AutoGluon model search. The agent does the feature engineering, while the harness owns the splits, the locked holdout and the scoring, so the agent can't inflate its own results. It improved over AutoGluon `best_quality` on 6/6 public datasets, at about $0.85 of LLM cost each.
`Python` `AutoGluon` `LightGBM` `LLM agents` `uv` `CI`

**[GenHack 4: Urban Heat Island bias correction](https://github.com/mohymabrouk/genhack4-hackathon)**: 🏆 **1st place**, team PentaGen. We corrected the urban heat island bias in ERA5-Land temperatures with an ensemble of XGBoost, Random Forest, Ridge and Quantile Regression. I owned the data engineering: downloading and processing about 200GB of satellite (Sentinel-2), reanalysis (ERA5) and weather-station data.
`Python` `XGBoost` `Geospatial data` `Flask`
